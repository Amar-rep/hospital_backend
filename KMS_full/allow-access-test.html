🔐 KMS Allow Access Test

Test the DocumentController /api/files/allow-access endpoint

ℹ️ What does this do? This endpoint grants access to a group by encrypting the group key with the receiver's public key. After this, the receiver will be able to access files in the specified group.
📝 The Keccak-256 hash of YOUR public key (you are granting access)
👤 The Keccak-256 hash of the RECEIVER's public key (who you're granting access to)
📁 The ID of the group you want to grant access to (you must be the owner or have admin rights)
🎲 Random value for the operation (if not provided, backend will generate one)
✍️ Your signature in Base64 format (proves you own the private key for sender_keccak)
